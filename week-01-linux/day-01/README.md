# Week 1 Day 1 — Linux Fundamentals

## What I Learned

- Navigating the Linux filesystem using `pwd`, `ls`, and `cd`
- Creating files and directories using `touch` and `mkdir`
- Reading files using `cat` and `less`
- Moving files and directories using `mv`
- Removing files and directories using `rm`
- Writing and modifying file contents using `echo`, `>`, and `>>`
- Understanding file permissions using `chmod`
- Making a shell script executable using `chmod +x`
- Running a script using `./deploy.sh`
- Understanding the difference between files and directories

## Practical Work

I created a simple application structure containing:

- `config.txt` — application configuration
- `app.sh` — shell script that starts the application
- `app.log` — application log
